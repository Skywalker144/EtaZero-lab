# Reference code and attribution

[reference_sources.json](reference_sources.json) records the inspected source revisions, paths and SHA-256 values. KataGo is pinned to `d91ea855110dae533f0aada947b2b7d78cc8a4e1`; KataGomo is pinned to `df152116e3787c75c6a3de099d261ca092b7dfc1`. MuZero and SkyZero working-tree references are identified by their registered file hashes. Builds and normal runs use EtaZero code and the selected Python environment; external source checkouts are needed only for optional reference checks.

KataGo copyright and MIT terms are retained in [licenses/KataGo.txt](licenses/KataGo.txt), and KataGomo terms in [licenses/KataGomo.txt](licenses/KataGomo.txt). These notices also cover the corresponding KataGo-derived modules inspected through SkyZero. Runtime semantics are maintained in the algorithm and implementation documents; this file records attribution and adaptation scope.

The Muon kernels in [python/etazero/_vendor/muon.py](python/etazero/_vendor/muon.py) are copied unchanged from the registered `KataGoMuon` source. Keller Jordan's MIT notice is retained in [licenses/Muon.txt](licenses/Muon.txt), alongside KataGo's MIT notice for its extensions. EtaZero exposes single-device Muon, NorMuon and Aurora, adapts parameter roles and the LR/WD policy, and raises on incompatible optimizer state instead of dropping it. Source DDP remains outside the single-device learner. Optional auxiliary Adam LR, decay floors, Newton–Schulz/Polar Express and Aurora PP controls are passed through with their training state.

MiniZero's small-span latent normalization guard is adapted from `scale_hidden_state` at revision `394b2e483d00cb658d5a24ccca297f864c3280c7`. Its Apache-2.0 license and RLG Lab copyright notice are retained in [licenses/MiniZero.txt](licenses/MiniZero.txt); EtaZero retains FP32 masked reductions and implements the guard without an in-place update.

Gumbel root scheduling, mixed-value Q completion, policy targets and deterministic interior selection are adapted from Google DeepMind Mctx `428bfb7e1c931715cd3d74f9c65e9991afd86df8` (Copyright 2021 DeepMind Technologies Limited). Apache-2.0 terms are retained in [licenses/Mctx-Apache-2.0.txt](licenses/Mctx-Apache-2.0.txt). EtaZero implements C++ double statistics, bounded parallel reservations, WDL/latent adapters and int16 target packing; it does not depend on JAX at runtime. SkyZero V7.19 and MiniZero were inspected as engineering references; their different budget/scaling rules are not used as numerical oracles.

EtaZero's CUDA upload prefetch, training-view cache, restorable snapshot eviction, persistent worker protocol, exact input cache keys and separate RNG streams are local adaptations. Source RNG sequences, scheduling, throughput and complete repository-level equivalence are not claimed. Go pass is retained. Score/ownership/seki supervision is excluded. Draw and no-result remain separate channels; ordinary non-Go draws never become no-result labels.

SGF and PositionSample parsing uses the pinned KataGo dataio implementation and its original hash convention. `sgf_handicap.cpp` extracts the fixed-handicap routine from source playutils; `benchmark_sgf.h` extracts the benchmark corpus from source testcommon.cpp, retaining MIT attribution.

The named-network vendor changes imports and custom-op namespaces, extracts the boolean environment parser, uses equivalent tensor-derived dtype casts for inference tracing, and repairs two metadata defaults: the config-taking feature-count helper uses its argument, and the metadata encoder inherits the trunk's default ReLU activation when unspecified. The architecture catalog values and tensor kernels are retained. Training retains source layout, masking, flex-attention and compile preparation. LibTorch reference export uses tensor traces, folds RepVGG branches, and preassembles frequency-mixing TAB kernels. Ordinary RL rejects metadata presets; secondary HumanSL CUDA inference uses source SGFMetadata profiles with the actual player and board area.

The dedicated CUDA backend vendors the pinned `neuralnet/cuda*`, model descriptors and their core dependencies. Adaptations expose raw outputs without KataGo NNEvaluator coupling, add four outcomes and multigame policy layouts, and extend model descriptors with MuZero latent projections. `neuralnet/muzerohelpers.{h,cu}` are EtaZero GPU latent normalization/packing kernels. The vendored dependencies retain their notices: [cuDNN frontend MIT](cpp/external/katago/external/cudnn-frontend/LICENSE.txt), [CUTLASS BSD-3-Clause](cpp/external/katago/external/cutlass/LICENSE.txt), [filesystem MIT](cpp/external/katago/external/filesystem-1.5.8/LICENSE), and [half MIT](cpp/external/katago/external/half-2.2.0/LICENSE.txt). CUDA, cuDNN and cuBLAS runtime libraries are external build dependencies.

Optional reference check locations and coverage are listed in [验收与限制](docs/implementation.md#验收与限制). Historical V0 results retain their own source/configuration identities in the repository-level audit records; they are not current V1 acceptance evidence.

The native session and public analysis server adapt KataGo GTP/AsyncBot and JSON request semantics. Public JSON jobs use priority scheduling and persistent analysis workers; mutable GTP/Web boards remain serialized with cancellation. Go supports rectangular boards, SGF, applicable rule/parameter/handicap/time extensions and raw NN symmetry selection. Score/ownership/seki predictions and their unfinished-position estimation remain excluded, as do full passing/dame/anti-mirror enhancements. Debug text formatting is local; Xiangqi coordinates are not a full UCCI protocol.

`cpp/external/nlohmann/json.hpp` vendors Niels Lohmann JSON for Modern C++ 3.8.0, unmodified from SkyZero V8.1 KataGo. Its MIT license and copyright are retained in the file header; source hashes are recorded in `reference_sources.json`.

围棋规则、NN 输入和 GraphHash 复制自上述 KataGo commit，位于 `cpp/external/katago/`，按 MIT 条款保留；编译规则、特征、图身份及必要 core 依赖，棋盘编译上限为 25。图共享的历史折叠、非法着重评估和根边清理按来源接入 EtaZero 的 WDL 搜索；没有接入完整 KataGo 引擎或其分数效用。

中国象棋使用 Pikafish `545c4e3b251afbb94f493c6c5f32549f900e76fd` 的 Position、Attacks、Bitboard、MoveGen 和规则裁定，位于 `cpp/external/pikafish/`。许可证为 [GPL v3](licenses/Pikafish.txt)，包含该代码的构建受相应分发条款约束。适配增加了状态复制入口和规则裁定原因输出（沿用原判定顺序），并去掉不参与规则的置换表／搜索历史预取；没有使用 Pikafish 搜索、NNUE 评估或网络权重。来源递归头文件随代码保留。


`cpp/external/katago/search/localpattern.{h,cpp}` are copied unchanged from the pinned KataGo source for Go pattern bonuses. `cpp/src/search/timecontrols.cpp` and its header adapt KataGo TimeControls to the common board-area/occupied-point interface; search timing, HumanSL, pattern table loading, history dropout and auxiliary targets are derived from the same source, with the documented WDL, multigame and data-format adaptations.
