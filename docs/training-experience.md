# AlphaZero / KataGo 训练经验

以下是我在 AlphaZero / KataGo 相关实验中的经验观察。数值是近似范围，机制解释属于直观理解，适用范围以当时的实验设置为准。

## 1. 自对弈平均局长的变化

在 15×15 Renju 中，自对弈平均局长（selfplay avglen）通常经历四个阶段：

- **冷启动**：局长较长，可能在 60 多步。
- **首轮训练后快速下降**：很快跌至低谷，可能只有十多步。
- **快速回升**：随后较快回升至四五十步。
- **缓慢增长**：再随训练推进逐渐增长。

我的直观解释是：模型先学会了“活三 → 活四 → 成五”的进攻手段，但还不会有效防守，因此一方能迅速取胜，平均局长骤降。随着模型学会防守，对局开始拉长；之后双方逐步掌握更复杂的策略，局长增长也趋于缓慢。

## 2. 搜索与模型规模的经验规律

- **评估访问量**：在此前实验覆盖的范围内，搜索访问量每翻一倍，Elo 大致增加一个常数，约为 **100～200**。也就是 Elo 与访问量的对数近似呈线性关系。
- **模型规模**：在此前的 AlphaZero 实验中，更大的模型通常表现出更快的 Elo 增长，也有更高的 Elo 上限。

## 3. NBT 与 Transformer

在参数量相近的对照中，Transformer（TF）的样本效率约为 NBT 的 **两倍**：达到相近 Elo 所需的训练样本量约为 NBT 的一半，观察到的 Elo 上限也更高。

代价是单次推理和 batch 推理都比 NBT 慢。因此，样本效率优势不能直接等同于实际时间效率优势。
